Türkiye İnteraktif Harita Web Sitesi

Bu proje, kullanıcıların Türkiye’yi daha iyi tanımasını ve tanıtmasını amaçlayan interaktif bir web sitesidir. Projede MVC mimarisi kullanılmış, C# dili ile geliştirilmiş ve SQL Management Studio veritabanı kullanılmıştır.

Proje Hedefi

Kullanıcılara Türkiye’nin illerini ve ilçelerini görsel ve interaktif bir şekilde tanıtmak

Kullanıcıların deneyimlerini paylaşabileceği yorum bölümleri oluşturmak

Site yönetimi için admin paneli ile tam kontrol sağlamak

Proje Yapısı
1. Ana Sayfa

Üst bar:

Sol tarafta illeri gösteren liste

Ortada ana sayfaya dönme ikonu

Sağ tarafta giriş yap, kaydol ve il arama çubuğu

Ekranın ortasında etkileşimli Türkiye haritası

Harita arka planında Türkiye’ye ait fotoğraflar oynatılmaktadır

2. İl Detay Sayfası

İle ait ilçe haritası

İl hakkında genel bilgiler

Alt kısımda kullanıcıların yaptığı yorumlar

Yorum yapabilmek için kullanıcı hesabı açmak veya giriş yapmak gereklidir

3. Admin Paneli

İl oluşturma (plaka, nüfus, ilçe haritası, rakım vb.)

İlçe yönetimi

Yorumlar yönetimi

Fotoğraflar menüsü

Admin paneli sayesinde site tamamen yönetilebilir

Kullanılan Teknolojiler

C# – Backend ve iş mantığı

MVC Yapısı – Düzenli ve yönetilebilir proje mimarisi

SQL Management Studio – Veritabanı yönetimi

HTML5 / CSS3 / JavaScript / Bootstrap – Frontend ve kullanıcı etkileşimleri

SVG Haritalar – İl ve ilçe görselleştirmesi

Özellikler

Türkiye haritasında interaktif gezinti

İl ve ilçeler hakkında detaylı bilgiler

Kullanıcı yorumları ile etkileşim

Admin paneli ile site yönetimi ve içerik kontrolü
